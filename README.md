# IT Support / Help Desk Portfolio

Hi, I'm Juan — this repository contains documentation and reference material I've created while preparing for a career in IT support and help desk technical roles. Everything here reflects my hands‑on learning, troubleshooting practice, and growing understanding of core IT concepts.

My background includes practical experience with networking fundamentals, Windows administration, Microsoft 365 management, and structured troubleshooting. I’ve built this portfolio to demonstrate how I approach problems, document solutions, and continue developing my technical skills.

Contents
network_troubleshooting_reference.md
A structured, layer‑by‑layer diagnostic framework for resolving “no internet” issues. Covers DHCP, local network checks, DNS failures, reachability tests, and cross‑platform command references (Windows/macOS/Linux). Includes a full example of a support call from intake to resolution.

m365_admin_center_guide.md
A hands‑on walkthrough of Microsoft 365 admin center tasks: user provisioning, group creation, shared mailboxes, password resets, and permission management — with explanations based on the principle of least privilege.

active-directory-entra.md
Notes and references related to Active Directory and Entra ID fundamentals, including identity management concepts and common administrative tasks.

More documentation will be added as I complete additional help desk practice, ticket workflows, and troubleshooting exercises.
